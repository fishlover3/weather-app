🌤️ Weather App (تطبيق الطقس)
تطبيق طقس تفاعلي تم بناؤه باستخدام React.js للعرَض الفوري لحالة الطقس ودرجات الحرارة بدقة، مع دعم كامل للغتين العربية والإنجليزية وتغيير اتجاه الواجهة (RTL/LTR) بأسلوب عصري.

🚀 المميزات (Features)
🌍 دعم اللغات (Multi-language Support): تحويل كامل بين اللغة العربية والإنجليزية باستخدام react-i18next.
↔️ تكيّف الاتجاهات (RTL/LTR): ضبط تلقائي لتنسيق عناصر الواجهة بحسب اللغة المحددة.
🌡️ بيانات طقس فورية: جلب درجة الحرارة الحالية، العظمى، والصغرى، مع وصف حالة الجو والأيقونة المناسبة من خلال WeatherAPI.
📅 تنسيق التاريخ والوقت: استخدام مكتبة moment.js لعرض التاريخ باللغة المحددة لحظياً.
🔒 حماية البيانات (Security): تأمين مفتاح الـ API باستخدام متغيرات البيئة .env لمنع تسريب المفتاح على GitHub.
⚡ إدارة الطلبات (Performance & Cleanup): التعامل مع إلغاء الطلبات أثناء الـ Unmount بـ AbortController لتجنب أخطاء الـ Memory Leaks.
🛠️ التقنيات المستخدمة (Tech Stack)
React.js (Hooks: useState, useEffect)
Material UI (MUI) (عناصر الواجهة والـ Typography والـ Container)
Axios (لإجراء طلبات الـ HTTP)
i18next / react-i18next (للترجمة والتدويل)
Moment.js (للتعامل مع التواريخ)
CSS3 & Flexbox (للتنسيق الجذاب والـ Responsive)
